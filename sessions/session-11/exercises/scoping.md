# Project scoping worksheet

Fill this in during the first half hour of session 11, then copy the top half into your
project's `README.md`.

---

## The question

_One or two sentences. Specific enough that it has an answer._

> Using ................................................ (dataset),
> answer ................................................ (question),
> producing a chart and a short written conclusion, generated by a script that runs start to
> finish.

**The test:** can you say what "done" means in one sentence?

> Done means: ..........................................................................

**The second test:** would you be interested in the answer either way? If only one outcome
is interesting, this is an argument rather than an analysis.

---

## The data

- **What it is:**
- **Where it is right now** (be honest: on your laptop, or somewhere you hope you can get
  it?):
- **How many rows, roughly:**
- **Does it have a date column?** A numeric column? A couple of categorical columns?
- **Is there a second table, or something you could split into one?**

**If you cannot download this in ten minutes, change the project.** Not the timeline, the
project. A project without data is not a project.

## Milestones

Four or five, with rough dates. Fifteen minutes on this, no more.

| By when | Milestone |
|---|---|
| Today | Repo, venv, data in place, row count printing |
| | |
| | |
| | |
| | Written conclusion, delete-and-rerun test passes |

The dates are not for accountability. They are so that when day 9 arrives and you have no
chart, you notice in time to cut the stretch goal rather than running out of fortnight.

---

## Setup checklist

- [ ] Repo created on GitHub and cloned
- [ ] Structure copied from `project/`
- [ ] venv created, activated, pandas and matplotlib installed
- [ ] `pip freeze > requirements.txt`
- [ ] Question, and all three levels, written at the top of the README
- [ ] Data in `data/`, with its source noted in `data/README.md`
- [ ] A script that loads the data and prints the row count
- [ ] It runs
- [ ] Committed and pushed
- [ ] Session 12 in the calendar
