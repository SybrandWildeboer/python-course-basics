How the work is organised

Notebooks are where the work happens

Each session has a notebooks/ folder. Files ending -exercise.ipynb are the ones to fill in; -solved.ipynb are the answers. Open them in VS Code, or run jupyter lab from the repo folder.

Everything also exists as a plain .py script, in demos/, exercises/ and homework/. That is on purpose: a notebook is for exploring, a script is for running, and seeing both is how the difference makes sense. Anything interactive, like the session 2 guessing game, is a script only.

python3 tools/nbtool.py check     # are the notebooks valid and output-free?
python3 tools/nbtool.py run       # do they all still run?

Running the slides

You are already running the server, so you are set

Open a deck and use ← and → to move. Press o for a grid of every slide, n for speaker notes, t to switch between light and dark, f for full screen, and ? for the full list.

To export a deck as PDF, open it and press p, then choose Save as PDF with landscape orientation and background graphics turned on.

If you ever need to start the server again:

python3 serve.py
