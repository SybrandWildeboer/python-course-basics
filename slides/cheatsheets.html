Using them

A reminder, not a lesson

Each sheet is the course on one page: only what the sessions teach, in the words they use, with examples on the listening log. Each box names the session it comes from, so when a line does not make sense, go back to that session's notebook rather than searching the web.

Every Python, pandas and SQL snippet was run against this repository's data, and the numbers in the comments are what it printed. Run them yourself from the repository root and you should get the same.

Printing

Print from the browser with Ctrl P (Cmd P on a Mac). The sheets switch to black on white, one box after another, and the toggle and navigation are left off the paper.

Longer references

The session walkthroughs have every example from the slides, with comments: files_and_csv.py, git_commands.md, session 6 SQL, session 7 SQL, dataframes.py, cleaning.py and charts.py.
