The question firstSession 7

A chart is an answer to a question. Get the numbers with pandas, sorted, before drawing anything:

by_genre = (plays.groupby("genre")["minutes_played"]
            .mean()
            .sort_values(ascending=False))
print(by_genre.round(1).head(3))     # Jazz 6.6, Electronic 5.3, ...
top_genre, top_minutes = by_genre.index[0], by_genre.iloc[0]

Sorted bars make the ranking the first thing a reader sees.

Chart types

Bar: categoriesSession 7

fig, ax = plt.subplots(figsize=(8, 4.5))
bars = ax.bar(by_genre.index, by_genre.values, color="#4f6ddb")

ax.set_title(f"{top_genre} plays last longest: {top_minutes:.1f} minutes on average")

ax.bar_label(bars, fmt="{:.1f}")                  # the value on each bar

fig.savefig("output/minutes_by_genre.png", dpi=150, bbox_inches="tight")
plt.close(fig)

The title states the answer: "Jazz plays last longest: 6.6 minutes on average", not "Minutes per genre".

per_month = plays.groupby(plays["played_at"].str[:7]).size()

A line says "this follows from that", which is only true when the x-axis has an order. Months, days, years: a line. Genres, devices, artists: bars.

Same numbers, two stories. Bars always start at zero: the length of a bar is the number.

Pointing the reader

Reference lines and annotationsSession 7

plays["date"] = pd.to_datetime(plays["played_at"])
monthly = plays.set_index("date").resample("MS").size()   # one row per month
average = monthly.mean()
peak_date, peak = monthly.idxmax(), monthly.max()

fig, ax = plt.subplots(figsize=(10, 4.5))
ax.plot(monthly.index, monthly.values, marker="o", color="#4f6ddb")
ax.axhline(average, color="#b8bec9", linestyle="--", linewidth=1)   # a reference line
ax.annotate(f"{peak_date:%B %Y}: {peak}", xy=(peak_date, peak), xytext=(15, 8),
            textcoords="offset points", arrowprops={"arrowstyle": "->"})
ax.set_title(f"Every summer falls below the average of {average:.1f} plays a month")
ax.set_ylabel("plays per month")
ax.set_ylim(0, 145)
ax.spines[["top", "right"]].set_visible(False)
fig.savefig("output/plays_per_month_annotated.png", dpi=150, bbox_inches="tight")
plt.close(fig)
print(round(average, 1), f"{peak_date:%B %Y}", peak)   # 91.0 October 2024 127

ax.axhline(y) draws a line across the chart, so every point reads as above or below it. ax.axvspan(start, end) shades a band, such as a summer. ax.annotate puts a label on one point: xy is the point, in data units, and xytext with textcoords="offset points" moves the text a little away from it. %B %Y in an f-string writes a date as "October 2024".

Small multiplesSession 7

plays["quarter"] = plays["date"].dt.to_period("Q").dt.start_time
quarterly = plays.pivot_table(index="quarter", columns="genre",
                              values="play_id", aggfunc="count")

fig, axes = plt.subplots(2, 4, figsize=(13, 5.5), sharex=True, sharey=True)
for ax, genre in zip(axes.flat, quarterly.columns):   # the eight charts, one by one
    ax.plot(quarterly.index, quarterly[genre], color="#4f6ddb", linewidth=2)
    ax.set_title(genre)
    ax.set_xticks([pd.Timestamp("2024-01-01"), pd.Timestamp("2025-01-01")], ["2024", "2025"])
    ax.spines[["top", "right"]].set_visible(False)
for ax in axes[:, 0]:                                  # the first column only
    ax.set_ylabel("plays per quarter")
axes[0, 0].set_ylim(bottom=0)                          # once, after the loop
fig.suptitle("Electronic and Folk are the two biggest genres in every quarter")
fig.savefig("output/genres_by_quarter.png", dpi=150, bbox_inches="tight")
plt.close(fig)
print(quarterly["Rock"].max(), quarterly["Electronic"].min())   # 24 47

Eight lines on one chart is spaghetti; one small chart per genre is readable. sharey=True keeps it honest: without it each panel stretches to fill its box, and Rock, never above 24, looks as big as Electronic, never below 47. With a shared axis, set the bottom to zero once, after the loop; on every panel it clips the others.

Highlight one, grey the restSession 7

GREY, HIGHLIGHT = "#b8bec9", "#d55e00"
by_genre = plays.groupby("genre")["minutes_played"].mean().sort_values()
colours = [HIGHLIGHT if genre == "Jazz" else GREY for genre in by_genre.index]

fig, ax = plt.subplots(figsize=(8, 4.5))
bars = ax.barh(by_genre.index, by_genre.values, color=colours)
ax.bar_label(bars, fmt="{:.1f}", padding=3)
ax.set_title(f"Jazz plays last longest: {by_genre['Jazz']:.1f} minutes on average")
ax.set_xlabel("average minutes per play")
ax.spines[["top", "right"]].set_visible(False)
fig.savefig("output/jazz_highlighted.png", dpi=150, bbox_inches="tight")
plt.close(fig)
print(by_genre.index[-1], round(by_genre.iloc[-1], 1))   # Jazz 6.6

Grey is context, one strong colour is the thing the title is about. For lines, the same recipe: draw every line grey and thin, then the one that matters last, thick and in colour, and label it at the end of the line with ax.text instead of a legend.

Colour for every readerSession 7

Okabe-ItoHexUse it for
blue#0072b2The data
orange#e69f00The one thing, against blue
vermillion#d55e00A highlight against grey
sky blue#56b4e9A second series
green#009e73A third series
  • Colour should mean one thing. Not a colour per bar "to look nice".
  • Never red against green as the only difference: about one man in twelve cannot tell them apart. Blue against orange is safe.
  • Never colour alone: label lines directly and put numbers on bars.
  • The colours should differ in lightness too, so the chart survives a greyscale printer.
  • When colour shows an amount, as in a heatmap, use one colour from light to dark, "Blues" or "viridis", never a rainbow.

Finishing

SavingSession 7

fig, ax = plt.subplots(figsize=(8, 4.5))
ax.bar(by_genre.index, by_genre.values)
fig.savefig("output/chart.png", dpi=150, bbox_inches="tight")   # save FIRST
plt.close(fig)                                                  # then let it go
print(os.path.exists("output/chart.png"))                       # True

dpi=150 is sharp enough for a slide. bbox_inches="tight" stops long labels being cut off. In a script, plt.savefig() after plt.show() writes a blank picture. output/ is gitignored.

Checklist for every chartSession 7

  • Can I say the question in one sentence?
  • Does the title give the answer, not the topic?
  • Bars for categories, a line for time?
  • Do the bars start at zero?
  • Units on the axis, numbers rounded to what a person would say?
  • Would it make sense to someone who was not in the room?
