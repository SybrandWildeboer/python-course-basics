# Python, SQL & Git

A twelve session course for someone who has never written a line of code, built around one
dataset from start to finish. Twelve two-hour sessions, one to one, with two to four hours of
homework in between.

Slides, notebooks, exercises, solutions and homework all live in this repository.

## Start here

```bash
git clone https://github.com/SybrandWildeboer/python-course-basics.git
cd python-course-basics
python3 serve.py
```

That opens the course index in your browser, which links to every session.

## How the work is organised

**Notebooks are where the work happens.** Each session has a `notebooks/` folder:

- `*-exercise.ipynb` and `*-homework.ipynb` are yours to fill in
- `*-solved.ipynb` are the answers, for after you have tried

Open them in VS Code, or run `jupyter lab` from this folder.

**Everything also exists as a plain `.py` script**, in `demos/`, `exercises/` and
`homework/`. That is deliberate. A notebook is for exploring; a script is for running. Seeing
both is how the difference makes sense, and session 10 is about turning one into the other.
Anything interactive, like the session 2 guessing game, is a script only, because `input()`
is awkward in a notebook.

```
slides/                 one deck per session, plus the course index
sessions/session-NN/
    notebooks/          where you work
    demos/              the same material as scripts
    exercises/          script versions of the live exercises
    solutions/          worked answers
    homework/           homework, with answers in homework/solutions/
    README.md           run sheet and notes for whoever is teaching
data/                   the dataset: CSVs, a messy version, a SQLite database
cheatsheets/            quick reference per topic
docs/                   install guide and troubleshooting
instructor/             prep and course-wide notes
my-work/                your scratch space
project/                your final project, from session 11
tools/                  scripts that check the course materials
```

## The dataset

One dataset carries the whole course: a personal music listening log of 2,183 plays across 40
artists and two years. It appears in four shapes.

| Shape | Where | Used in |
|---|---|---|
| Clean CSVs | `data/clean/` | sessions 4, 8 |
| SQLite database, three tables | `data/music.db` | sessions 6, 7, 10 |
| Deliberately messy CSV | `data/messy/` | session 9 |
| Everything above | | session 10 onward |

It is generated by a seeded standard-library script, so the numbers on the slides always
match the numbers on your machine. If you ever break it:

```bash
python3 data/scripts/build_dataset.py
```

## The twelve sessions

| # | Session | Core skill |
|---|---|---|
| 1 | Setup and first contact | Environment, notebooks, variables, types, f-strings |
| 2 | Control flow | if/else, loops, reading error messages |
| 3 | Functions | def, return versus print, scope |
| 4 | Lists, dictionaries and files | Data structures, CSV in and out |
| 5 | Git and GitHub | Commits, branches, pushing to your own repo |
| 6 | SQL foundations | SELECT, WHERE, GROUP BY, HAVING |
| 7 | Joins and shaping | Joins, CTEs, and how a join makes your totals wrong |
| 8 | pandas | DataFrames, filtering, groupby, merge |
| 9 | Cleaning and visualization | Missing data, types, matplotlib |
| 10 | Putting it together | Pipeline script, virtual environments, project layout |
| 11 | Project scoping and setup | Scope, milestones, a first working run |
| 12 | Presentation and next steps | Review, and a map of where to go next |

## Checking the materials

If you change anything, these three will tell you whether it still holds together.

```bash
python3 tools/check_slides.py     # every slide fits, no overflow, notes present
python3 tools/check_sql.py        # every query runs, and returns the row count claimed
python3 tools/nbtool.py check     # notebooks are valid and carry no saved output
python3 tools/nbtool.py run       # every notebook still runs top to bottom
```

`check_slides.py` and `nbtool.py run` need a couple of extras:

```bash
pip install playwright nbformat nbclient ipykernel
playwright install chromium
```
